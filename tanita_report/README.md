# 臺北市12週健康促進介入計畫-成果報告產生器（TANITA MC-780）

讀取 TANITA MC-780（GMON 軟體）匯出的 `.xls`，可以是英文欄位版或中文欄名版。資料可包含固定測量日的 2 次以上量測，允許部分人缺測。程式會自動產出：

| 檔案 | 用途 | 對象 |
|---|---|---|
| `<職場>_成果報告.html` | 互動式成果報告（可依性別、年齡層篩選），單一檔案、可離線開啟 | 職場 |
| `<職場>_成果報告_A4.pdf` | 同內容的 A4 直式列印版（約 10 頁） | 職場 |
| `<職場>_驗算.xlsx` | 以 Excel 公式重算主要統計量，含 Python 對照值與差異 | **僅限分析人員** |
| `<職場>_驗算_寬格式.sav`、`_長格式.sav` | SPSS 資料檔，已設定中文變項標籤與數值標籤 | **僅限分析人員** |
| `<職場>_驗算.sps` | SPSS 語法：GLM 重複測量（含分組交互作用與趨勢圖）、Friedman、配對 t（含效果量）、個人變化分類、Cochran's Q、McNemar、卡方與趨勢檢定、MIXED 混合模型 | 分析人員 |
| `<職場>_跨職場摘要.csv` | 一列彙總統計，供 `combine.py` 合併成跨職場比較表 | 分析人員 |

## 使用方式

```bash
pip install pandas scipy statsmodels openpyxl xlrd pyreadstat
python build_report.py 匯出檔.xls [輸出資料夾] --name 職場名稱   # HTML + Excel + SPSS + PDF
python build_report.py 匯出檔.xls --name 職場名稱 --no-pdf
python build_report.py 匯出檔.xls --name 職場名稱 --no-sex   # 使用者指定時：不做性別分層、時間×性別交互作用與性別卡方
```

PDF 需要 Node.js 與 Playwright。沒有的話，用瀏覽器開啟 HTML 後選「列印 → 另存為 PDF」，版面相同。

多家職場的作業流程見 repo 根目錄的 `CLAUDE.md`。

> `output/`、`*.xls`、`*.xlsx`、`*.sav` 已列入 `.gitignore`。本 repo 是公開的，**請勿提交原始資料或驗算檔**。

## 資料處理

- **量測次別**：依測量日分群，相隔超過 7 天算新的一次：T1＝前測、T2＝後測、T3＝追蹤測。報告顯示各次相對前測的週數。
- **主要指標**：BMI、體重、體脂率、總體肌肉量（TANITA 推定肌肉量）、內臟脂肪等級。
- **重複量測**：同一人同一次量了多次，保留最後一筆。性別不一致或身高差異超過 2 cm 時列為警告。
- **分析對象**：三次皆參加者（主分析），以及只參加兩次且其中一次是前測者（前測＋後測或追蹤測其一，合併分析）。未參加前測（例如只有後測→追蹤測）或只量測一次者，不納入任何分析，報告只註明人數。
- **年齡層**：以首次量測年齡分為 40 歲（含）以下、41–50、51 歲以上（固定，21 家一致）。
- **前測體位**：前測 BMI ≥ 24 與 < 24。
- **個人變化**：前測 vs 最後一次量測（三次皆參加者為追蹤測、參加兩次者為介入後）。
  - **身體組成類型**（判定好壞的主要依據）：脂肪量（體重 × 體脂率）與總體肌肉量變化各以 ±0.5 kg 判定增加／持平／減少，組合為減脂保肌、增肌（有利）、脂肪與肌肉同增或同減（需注意）、增脂、肌肉流失（不利）、持平。
  - **BMI、體重只看方向**：上升可能是增肌、下降可能是肌肉流失，因此只標示上升／持平／下降（變化達前測值 1%），報告中不標有利或不利。
  - 體脂率達 1 個百分點、總體肌肉量達前測值 1%、內臟脂肪等級達 1 級才算改善或變差。
  - 體重減少 ≥ 3%、≥ 5% 的人數，以及其中肌肉量未減少者（減重品質）。

## 統計方法（全部可在 SPSS 重現）

| 目的 | 方法 | 資料 | SPSS |
|---|---|---|---|
| 各次描述 | 平均、標準差、95% CI | 每次的納入分析者 | EXAMINE |
| **主分析**：三次是否不同＋趨勢圖 | 重複測量 ANOVA；Mauchly p < 0.05 時採 GG 校正；偏 η²；Bonferroni 兩兩比較；Friedman 為參考 | 三次皆參加者 | GLM /WSFACTOR |
| 參加兩次者 | 前測 vs 介入後（後測或追蹤測其一）配對 t 檢定（Wilcoxon 為參考） | 前測＋後測、前測＋追蹤測者合併 | SELECT IF TWO=1 + T-TEST PAIRS |
| 風險分類變化 | Cochran's Q（兩兩 McNemar，Bonferroni）；參加兩次者的 McNemar | 三次皆參加者；參加兩次者 | NPAR TESTS |
| 效果量 | Cohen's dz（平均變化 ÷ 變化量 SD） | 配對比較 | T-TEST /ES |
| 個人變化 | 改善／持平／變差人數、體重減少 ≥ 3%／≥ 5% | 納入分析者 | COMPUTE + FREQUENCIES |
| 各次組間比例 | Pearson 卡方，期望次數小於 5 的格子超過 20% 時改用 Fisher 精確檢定；年齡層另做線性趨勢檢定（linear-by-linear） | 每次的納入分析者 | CROSSTABS |
| 分層 | 各分層的重複測量 ANOVA；時間 × 性別、年齡層、前測體位交互作用（混合設計 ANOVA） | 三次皆參加者 | SPLIT FILE + GLM；GLM … BY |
| 敏感度分析 | 線性混合模型（隨機截距，REML），各次 vs 前測 | 所有至少量測一次者 | MIXED |
| 代表性 | 三次皆參加 vs 參加兩次者的前測值比較（Welch t、卡方） | 納入分析者 | T-TEST、CROSSTABS |

驗證紀錄：

- 重複測量 ANOVA 與交互作用的 F、Mauchly W、GG ε、p 值和 Friedman 檢定，都和 pingouin 套件的結果一致。
- Excel 公式結果和 Python 的差異都小於 1e-6。

## 隱私規則

- 報告只呈現彙總統計，不含編號、姓名或個人數值。
- 任何分析人數少於 `MIN_N`（10 人）就不呈現；網頁內嵌資料也不寫入該分層人數。
- 驗算檔和 .sav 用序號取代受測者編號，但仍屬個人層級資料，只供內部驗算使用。

## A4 直式 PDF 版型（約 11 頁）

| 節 | 內容 |
|---|---|
| 1 | 總體評價與建議 |
| 2 | 計畫概況（各次人數、參與型態、性別 × 年齡層組成） |
| 3–4 | 主要成果卡、趨勢圖 |
| 5 | 檢定分析：重複測量 ANOVA、參加兩次者配對比較（含效果量 d） |
| 6 | 健康分級變化、風險比例檢定 |
| 7 | 個人變化：體重減少 ≥ 3%／≥ 5%、各指標改善／持平／變差 |
| 8 | 分層分析：性別、年齡層、前測體位 |
| 9 | 不同性別、年齡層的風險比例比較：判定摘要格＋長條圖（完整檢定數值只在 HTML 的展開區，計算過程見 Excel／SPSS） |
| 10 | 結果可信度：樣本代表性、混合模型敏感度分析 |
| 11 | 方法、研究限制、名詞 |
