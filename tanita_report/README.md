# TANITA 身體組成前後測總體報告產生器

讀取 TANITA MC-780（GMON 軟體）匯出的 `.xls`，自動產出：

| 檔案 | 用途 | 對象 |
|---|---|---|
| `<職場>_身體組成總體報告.html` | 互動式總體報告（可依性別、年齡層篩選），單一檔案、可離線開啟 | 職場 |
| `<職場>_身體組成總體報告_A4.pdf` | 同內容的 A4 直式列印版 | 職場 |
| `<職場>_驗算.xlsx` | 以 Excel 公式重算的驗算檔，含 Python 對照值 | **僅限分析人員**（含去識別化個人資料） |
| `<職場>_驗算.sps` | SPSS 語法，讀入驗算檔即可重跑主要檢定 | 分析人員 |

## 使用方式

```bash
pip install pandas scipy statsmodels openpyxl xlrd
python build_report.py 匯出檔.xls [輸出資料夾]      # 產生 HTML + Excel + PDF
python build_report.py 匯出檔.xls --no-pdf           # 不需 PDF 時
```

PDF 需要 Node.js 與 Playwright（`npm i playwright`）。沒有的話，也可以直接用瀏覽器開啟 HTML，按「列印 → 另存為 PDF」，版面相同。

21 家職場：每家各一個匯出檔，逐一執行即可。版型相同，只換資料。

> `output/`、`*.xls`、`*.xlsx` 已列入 `.gitignore`。本 repo 為公開 repo，**請勿將原始資料或驗算檔提交**。

## 統計方法（對齊 SPSS 預設）

- **前後測**：配對 t 檢定，並計算 95% 信賴區間。若差值的 Shapiro-Wilk 檢定 p < 0.05，改以 Wilcoxon 符號等級檢定（漸近、無連續性校正）判定。兩者都列出，另附 Holm 多重比較校正。
- **分類變化**：二分類用 McNemar 精確檢定，多分類用 Bowker 對稱性檢定。
- **基線比例**：Pearson 卡方檢定。期望次數小於 5 的格子超過 20% 時，改用 Fisher 精確檢定（2×k 表格以 Freeman-Halton 法完整列舉）。
- **分層比較**：性別用 Welch t 與 Mann-Whitney U；年齡層用單因子 ANOVA 與 Kruskal-Wallis。
- **判讀標準**：BMI、體脂肪率依國民健康署成人健康體位標準；內臟脂肪等級依 TANITA 原廠標準。

## 隱私規則

- 報告只呈現彙總統計，不含編號、姓名或個人數值。
- 分層人數少於 `MIN_N`（預設 10 人，見 `analyze.py`）就不呈現；網頁內嵌資料也不寫入該分層人數。
- 驗算檔用序號取代受測者編號，但仍屬個人層級資料，只供內部驗算使用。

## A4 直式 PDF 版型規劃

頁面設定：A4 直式（210 × 297 mm），邊界上 14 mm、左右 13 mm、下 16 mm。頁首放職場名稱與報告名稱，頁尾放隱私聲明與「第 X / Y 頁」。

| 頁 | 內容 | 版面 |
|---|---|---|
| 1 | 標題列（職場、日期、儀器）、**總體評價與建議**：總評等級，以及體位、體脂肪、內臟脂肪、前後變化 4 張評價卡 | 雙欄卡片 |
| 2 | 建議事項（續）、參考依據、受測概況（人數卡、組成表、資料處理說明）、重點指標 6 張 KPI 卡 | 四欄統計卡 + 三欄 KPI |
| 3 | 各指標變化率森林圖（平均變化率 ± 95% CI，實心點表示顯著） | 滿版圖 |
| 4 | 前後測比較表（16 項指標，含兩種 p 值與 Holm 校正）、健康分級分布（BMI、內臟脂肪堆疊條）、McNemar 表 | 表格 + 雙欄圖 |
| 5 | 分層分析：性別、年齡層的變化量與組間檢定 | 兩張表 |
| 6 | 基線卡方檢定、樣本代表性（流失分析） | 兩張表 |
| 7 | 分節身體組成（左右手、左右腳、軀幹，共 24 項） | 滿版表 |
| 8 | 方法、研究限制、指標名詞與單位對照 | 定義列表 + 表格 |

設計重點：

- 配色採 Tropical punch：橘 `#FF8243`、粉 `#FFC0CB`、黃 `#FCE883`、青 `#069494`。前測用青色、後測用橘色；粉色與黃色只用於底色與分級色塊，不用作文字顏色，以確保可讀性。
- 每張卡片、表格與圖表都設為不跨頁；章節依上表強制換頁。
- 互動元件（篩選列、單一指標檢視）在列印時自動隱藏；PDF 固定呈現「全體」結果。
